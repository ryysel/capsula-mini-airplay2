# v1.6.0-rc.4 — музыкальная волна на экране Мини

**Предрелиз.** Последняя стабильная версия — [v1.5.5](https://github.com/ryysel/capsula-mini-airplay2/releases/tag/v1.5.5).

- На стоковой Мини четыре горизонтальных штриха раскрываются волной от центра. Внутренняя пара реагирует первой, внешняя следует за ней с задержкой 80 мс. Рисунок вдохновлён Лайт 2, но построен на реальном уровне PCM AirPlay, не на спектре и не на зацикленной анимации.
- Проверено на Mini владельца. Сохраняются штатная автояркость, возврат часов в паузе и приоритет штатной индикации. Арбитр и его протокол не менялись.
- На обеих стоковых колонках остаются пропорциональные цвета обложки, включая серый фон и тёмные оттенки. Приёмники, UI большой Капсулы и Alpine-пакет не изменились относительно rc.3. Эксперимент старта большой Капсулы остаётся в RC: стабильное устранение стартовых артефактов не заявлено.

## Включение

На стоковой Mini, из корня распакованного архива: `sh install.sh --upgrade --display-vu`.
Обычное обновление сохраняет предыдущий выбор. На чистой установке по умолчанию часы; `--clock` отключает VU. При **первом включении арбитра** нужна ручная перезагрузка, при обновлении только рисунка уже подключённого арбитра — нет. Полный установщик перезапускает AirPlay; не останавливайте `voice-agent` вручную.

Подробности: [Mini VU](MINI_DISPLAY_VU.md), [арбитр и автояркость](MINI_DISPLAY_ARBITER.md), [функции и установка](../README.md). Windows-мастер из ZIP предназначен только для Alpine-Мини.
