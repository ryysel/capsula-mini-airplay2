# v1.4.1 — быстрый аудиопрофиль и один LED-брокер

- Обе Капсулы: смещение **−1,7 с**, backend-буфер **0,10 с**, resync **0,050 с**, drift **0,002 с** — как в текущем fast-audio профиле Station-airplay.
- Обновление существующей установки теперь применяет эти значения, сохраняя имя, громкость и metadata.
- Для консервативного режима: `--timing synchronized` (**0,0 / 0,20**). Быстрый режим: `--timing fast_audio`, выбран по умолчанию.
- Исправлен запуск LED: старый standalone-clock останавливается по точному argv, если Busybox killall его пропустил. Два брокера больше не должны рисовать одновременно.
- Пауза/продолжение, приглушение мурчания во время AirPlay и цвета обложки сохранены.

## Установка / обновление

Капсула 2019: `sh install.sh` или `sh install.sh --timing synchronized`.

Мини: `sh install.sh --upgrade` или `sh install.sh --upgrade --timing synchronized`.

Перед обновлением установщик сохраняет резервные копии. Сам он не перезагружает колонку и не останавливает voice-agent.

## Ограничения проверки

Новые значения применены на обеих колонках, startup-лог большой Капсулы их подтвердил. Ранее на большой колонке были заикания с экспериментальным −1.0/0.1; причинность не измерялась. Профиль −1.7/0.1 требует проверки с реальным отправителем; одинаковые параметры с Алисой не гарантируют одинаковую акустическую задержку. Отрицательный offset жертвует синхронизацией с видео и другими AirPlay-приёмниками. Cold boot полного комплекта не проверен.
