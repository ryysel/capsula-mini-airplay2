# v1.5.5 — исправлен сброс аудиобуфера на Капсуле Мини

В v1.5.4 **конфиг пакета задавал 0,15 с**, но установщик стоковой Мини
перезаписывал его на **0,10 с** при установке и обновлении. В результате
возвращался ранее проблемный режим с недостаточным запасом локальной очереди.

## Исправление

- Stock-Мини: fast_audio теперь согласован с конфигом — **буфер 0,15 с,
  смещение −1,7 с** и для новой установки, и для `--upgrade`.
- Имя, нативная громкость, metadata и оформление сохраняются.
- `--timing synchronized` по-прежнему даёт **0,20 с / 0,0**.
- Добавлены три теста реального блока миграции: свежая установка,
  обновление старого конфига/идемпотентность, synchronized → fast_audio.
  На старом установщике тесты падают, после исправления проходят.
- Аудиобинарники, UPX/voice-agent и профиль большой Капсулы **не менялись**.
  Alpine-пакет также не менялся.

## Живая проверка и ограничения

На стоковой Мини применён буфер 0,15 с, приёмник подтвердил −1,7 с.
Владелец отметил улучшение воспроизведения. После запуска был участок
около 80 с без сообщений PA UNDERFLOW; ближе к завершению сеанса
зарегистрированы 5 underflow — причина требует отдельного разбора.
Поэтому этот выпуск исправляет **сброс настроек установщиком**, но не
обещает устранения абсолютно всех фризов или идеальной синхронизации.
Перезагрузка устройства и перепрошивка в рамках исправления не выполнялись.

## Обновление

На стоковой Мини, от root из распакованного каталога:

```sh
sh install.sh --upgrade
```

Если буфер уже вручную исправлен на 0,15 с, немедленное обновление
необязательно: релиз закрепляет настройку для будущих установок.

- `capsula-airplay-v1.5.5.tar.gz` — общий комплект с тремя пакетами.
- `capsula-airplay-mini-windows-v1.5.5.zip` — Windows-мастер **для Alpine-Мини**,
  не прошивальщик и не установщик stock-Мини по ADB.
- `SHA256SUMS.release` — контрольные суммы архивов.

Подробности: [README](https://github.com/ryysel/capsula-mini-airplay2#readme).
