# Проверки кандидата Windows/hostname — 30.10.2026

## Проверено

* `tests/test-install.sh` в одноразовом Alpine arm64-контейнере под qemu:
  `INSTALL_TESTS_PASS`. APK/rc-service подменены mock-командами: установки
  пакетов, сетевых соединений и настоящего воспроизведения в тесте нет.
* Новая установка: имя из синтетического /etc/hostname.
* Повторная установка сохраняет пользовательское имя; явный --hostname
  переводит на hostname; --name безопасно обрабатывает &, |, $().
* Пустое имя, кавычка, backslash и перевод строки отвергаются.
* Отличающийся установленный бинарник без --upgrade отвергается; --upgrade
  сохраняет backup и заменяет файл; неподходящая Alpine отвергается.
* Windows PowerShell 5.1: локальные SHA256 из распакованного комплекта,
  `-ValidateOnly`, mock полного подтверждённого сценария и отказа SCP.
  Пароль/ключ не отправлялись, реальные SSH/SCP подменены функциями.
* Нативные upstream-тесты без устройств:
  `PATCHED_DACP_EXACT_ID_AND_IPV4_GUARDS_SANITIZERS_PASS`,
  `PATCHED_STREAM_GAIN_LEASE_SANITIZERS_PASS`,
  `PREPLAY_STATUS_VOLUME_NO_AUDIO_PASS`.
  Они проверяют исходные патчи-кандидаты, НЕ означают их наличие в нашем бинарнике.

## Не проверено

* Реальная установка через мастер Windows → Alpine-колонка (включая пути с
  пробелами, парольный вход и прерывание питания во время установки).
* Новые кнопки, двусторонняя/групповая громкость, управление треками/LED на Капсуле:
  эти функции не установлены, в релизе их нет.
* Полная Go-suite Station-airplay: на хосте нет команды go; не выдаём запуск
  отдельных C-тестов за проверку всего проекта.

Существующая аудиосборка и nqptp не менялись. Ни одна колонка ради этих проверок
не перезапускалась, звук/громкость/evdev не трогались. AI-мониторинг не запускался.
