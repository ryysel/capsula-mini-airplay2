# v1.6.0-rc.2 — музыкальная анимация на экране Мини

**Предрелиз. Последняя стабильная версия — v1.5.5.**

## Новое: экран стоковой Мини

Во время AirPlay на месте часов — четыре столбика по уровню музыки.
Движение идёт волной слева направо, с мягким подъёмом/спадом и защитой
от дрожания на границах ступеней. В паузе возвращаются часы.

Это **VU-анимация, не частотный спектр**: четыре семисегментные цифры
показывают реальные значения PCM-envelope с небольшими задержками.
25 обновлений/с, без случайного «танца», записи звука или нового
декодирования аудио. Кольцо с цветами обложки и его калибровка не меняются.

Владелец проверил два ограниченных живых теста, подтвердил движение
под музыку и возврат часов, затем разрешил постоянную установку плавного
варианта. На его Mini установлен именно бинарник из этого пакета.
В 40-секундном тесте новых PA underrun не было; аудиоприёмник не заменялся.
Cold boot и полный тур speech/volume-приоритетов отдельно не проверены.
Стоковое управление часами остаётся активным; возможные конфликты требуют
обратной связи. Поэтому RC, а не обещание отсутствия любых дефектов.

## Включение / отключение

Только **Мини на родном Buildroot**, из `packages/mini-stock`:

```sh
sh install.sh --upgrade --display-vu
```

По умолчанию прежняя настройка сохраняется; на новой установке остаются
штатные часы, пока не передан `--display-vu`.
Чтобы выключить без переустановки и прерывания звука:

```sh
rm -f /data/local/capsula-airplay/etc/mini-display-vu.enabled /tmp/capsula-mini-display-vu
```

Или при следующем обновлении используйте `sh install.sh --upgrade --clock`.
Обычный установщик перезапускает AirPlay; это отличается от выполненной
на владельческой колонке UI-only замены. Не запускайте полный установщик,
если нельзя прерывать музыку. Резервная копия создаётся до обновления.

## Остальное

- Включены пропорциональные цвета обложки из rc.1 для обеих стоковых колонок.
- Эксперимент старта **большой** из rc.1 остаётся без изменений:
  повторные подключения ещё могут давать drop-late/underrun. Это НЕ
  завершённый фикс стартовых фризов. Подробности в описании rc.1.
- Приёмники Mini/Big, UI большой и legacy Alpine payload не менялись
  относительно rc.1. Дисплейная функция относится только к стоковой Mini.
- Настройки −1.7/0.15, громкость, аккаунты и прошивка не менялись.
