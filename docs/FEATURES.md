# Управление AirPlay на Капсуле — состояние на 30.10.2026

Что перенесено со Station-airplay и что осталось. Ниже — проверенное на
устройстве, а не план.

| Функция | Статус | Где |
|---|---|---|
| Имя комнаты | Работает | `install.sh` берёт `/etc/hostname` или `--name` |
| Значок Mini/Lite | Работает | `build/model-icon.patch`, модель `AudioAccessory5,1` |
| Громкость: телефон → колонка | Работает, в том числе до старта трека | `ap2-volume-sync` + IPC твикера, pre-play хук в приёмнике |
| Громкость: кнопки → телефон | Работает, задержка до 1 с | `ap2-bridge`, native-first на старте сессии |
| Play/Pause/Next/Previous | D-Bus готов | `ap2ctl pause/play/next/prev`; кнопки твикера пока не привязаны |
| Состояние «подключён, но не играет» | Работает | `GetControlStatus`, `preplay-event-channel` |
| Мультирум | Базовый AirPlay 2 | отдельно не проверялся |
| Индикация кольца из сессии | Работает с патченным твикером | команда `AP2 1/2/0`; патч отправлен автору твикера |
| Кнопка Алисы | Не применимо | на Alpine нет Алисы |
| Голосовые команды | Не применимо | нет ASR/ассистента |
| Групповая громкость | Не перенесена | для одной колонки не нужна |
| Duck/SetStreamGain | Интерфейс есть | не используется |

## Почему не triggerhappy + mpc

`mpc toggle/next` управляет MPD, а не потоком AirPlay с iPhone. Твикер уже
делает `EVIOCGRAB` и обрабатывает кнопки, поэтому второй evdev-обработчик не
ставится. Следующий шаг для кнопок — расширить action-кнопку самого твикера и
вызывать `ap2ctl`, а не добавлять параллельный сервис.

## Ограничения

- Задержка «кнопка → телефон» до 1 секунды (опрос моста раз в секунду).
- После подключения первое движение ползунка в течение ~1 с может быть
  поглощено защитой от эха.
- Индикация кольца и групповые сценарии — вне текущего этапа.
