# v1.6.0 — старт большой Капсулы и музыкальная волна Мини

## Капсула 2019

В первые восемь секунд AirPlay 2 в быстром профиле приёмник плавно
компенсирует умеренное отставание с помощью небольших поправок внутри
пакетов вместо выбрасывания целых пакетов. Постоянный профиль
**−1,7 с / 150 мс** не изменился. Режим синхронизации с видео, обработка
крупных скачков времени и алгоритм установившегося воспроизведения не менялись.

На одном запуске с тем же треком владелец подтвердил отсутствие треска
и заиканий. В первых 33 секундах диагностика зарегистрировала ноль
`drop late packet` и ноль `PA UNDERFLOW`; время выровнялось. Это результат
одного запуска, не проверка всех источников, сетей и холодных стартов.

## Стоковые Капсулы

- Кольцо передаёт пропорции цветов обложки, включая нейтральный фон и тени.
- На стоковой Мини музыкальная волна в стиле Лайт 2 реагирует на уровень
  AirPlay. Штатная автояркость работает, в паузе возвращаются часы.
  Для включения: `sh install.sh --upgrade --display-vu`. При первом
  подключении арбитра нужна ручная перезагрузка. Не останавливайте `voice-agent`.
- Относительно rc.4 изменился только бинарник приёмника большой Капсулы.
  Alpine-пакет и Windows-мастер для Alpine не менялись.

Инструкции, совместимость и откат — в [README](../README.md).
