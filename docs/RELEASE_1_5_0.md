# Релиз v1.5.0

## Что нового

Третий пакет — **Капсула Мини на родной прошивке**. Теперь один архив содержит
три пакета, а `install.sh` сам выбирает нужный:

| Система | Пакет |
|---|---|
| Alpine 3.24, aarch64 | `packages/mini-a113x/` |
| Buildroot, RK3308 (Капсула 2019) | `packages/capsula-2019/` |
| Buildroot, Amlogic A113X (Мини) | `packages/mini-stock/` |

Неизвестная система останавливает установку с объяснением. Windows-мастер
`Install-Windows.cmd` по-прежнему рассчитан на Мини с Alpine (SSH).

## Стоковая Мини

- shairport-sync 5.6.2 + nqptp 1.2.9 в `/data/local/capsula-airplay`.
- Прошивка, `voice-agent`, аккаунт и OTA-обновление не заменяются; в `/rom`
  ничего не пишется.
- Громкость телефона идёт напрямую в PulseAudio-синк `master`.
- Кольцо: 12 RGB-пикселей, палитра обложки, белая дуга громкости, дыхание без
  обложки; штатные анимации ассистента имеют приоритет.
- `KEY_PLAYPAUSE` пересылается в control-сокет shairport.
- Автозапуск: `S99airplay` + оверлейная замена `S50avahi-daemon`, потому что
  `rcS` раскрывает список скриптов до монтирования оверлея, а стоковый avahi
  не стартует без `--no-drop-root`.

## Проверено на устройстве

- установка и повторная установка с резервной копией, `--check`;
- mDNS-имя `VK Capsula Mini AirPlay (Спальня)`, порт 7000;
- остановка и запуск служб, **холодная загрузка** (avahi, nqptp, shairport,
  keys, ring поднимаются сами);
- root через ADB после загрузки;
- OTA-заглушка: `fwupdater` завершается с кодом 1, `NEED_UPDATE=0`.

Воспроизведение, громкость с телефона и кнопка требуют живой проверки
владельцем: без телефона эти события не воспроизводятся.

## Установка

```sh
sh install.sh --check --upgrade   # проверить условия
sh install.sh --upgrade           # установить или обновить
```

На стоковой Мини команды выполняются через ADB (`adb shell`) от root.

## Ограничения

- Проверенная прошивка — 44.90. Другая версия не заявлена.
- OTA-обновление пакет не отключает — это отдельное действие владельца.
- Резервные копии занимают место в `/data`; перед обновлением оставьте
  достаточно свободного места (установщик требует ≥ 25 МиБ).
