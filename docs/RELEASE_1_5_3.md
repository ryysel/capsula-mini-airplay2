# Релиз v1.5.3

Уменьшение размера поставки. Функции, звук, калибровка и панель не менялись.

## Размер

| | Было | Стало |
|---|---:|---:|
| Рендерер `capsula-ui` | 8,28 МиБ | 1,58 МиБ |
| Пакет на колонке, Мини | 14,5 МиБ | 5,3 МиБ |
| Пакет на колонке, 2019 | 27,9 МиБ | 5,4 МиБ |
| Свободно в `/data`, Мини | 22,0 МиБ | 28,5 МиБ |
| Свободно в `/data`, 2019 | 30,3 МиБ | 52,8 МиБ |

Рендерер собирается с `-trimpath -ldflags="-s -w"` и упаковывается
`upx --best --lzma`; после упаковки проверяется `upx -t` и реальный запуск
на обеих колонках. Дополнительно удалены резервные бинарники и пробные
каталоги прошлых экспериментов.

## Что не менялось

- `shairport-sync`, его конфиг и параметры задержки (−1,7 с, буфер 0,15).
- Калибровка кольца, панель на 8088, стоковые цвета.
- Патч `voice-agent` для единой громкости.

## Проверено

- Упакованный рендерер запущен на обеих колонках: панель отвечает,
  ручной цвет уходит в кольцо, конфиг и калибровка на месте.
- `upx -t` проходит; распаковка на колонке не нужна.

## Не проверено

- Холодная загрузка после обновления рендерера (отдельно).
- Инструментальный замер задержки; синхрон подтверждён владельцем на слух.

## Установка

```sh
sh install.sh --check --upgrade
sh install.sh --upgrade
```
