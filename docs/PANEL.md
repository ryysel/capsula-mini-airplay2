# Панель кольца (v1.5.2+)

Панель встроена в `capsula-ui` и работает на обеих стоковых колонках:
`http://<ip-колонки>:8088/`. Порт 80 занят стоковым `voice-agent`.

## Что можно делать

- Красить 12 пикселей по отдельности, заливать всё кольцо, включать белый
  или гасить.
- Выбирать основные цвета одним нажатием: красный, зелёный, синий, белый,
  жёлтый, голубой, пурпурный, оранжевый.
- Редактировать каждый из этих восьми цветов отдельно. Значение — это цвет,
  который реально уходит в кольцо. По восьми точкам интерполируется вся
  палитра обложки, поэтому правка оранжевого меняет и оранжевые места
  обложки, а правка белого задаёт баланс белого.
- Настраивать вживую яркость, глубину пульсации, насыщенность палитры и
  время перехода.
- Видеть предпросмотр кольца и палитру текущей обложки.
- Переключаться между авторежимом (обложка) и ручным тестом.
- Изменения сохраняются сами не позже чем через 2 секунды; кнопка
  «Сохранить» записывает сразу, а строка под ней показывает время записи.

Ручной тест на 2019 выводится через LED-брокер как обычный кадр, на Мини —
напрямую в `/dev/topleds`. Штатные анимации `voice-agent` (речь, громкость)
по-прежнему имеют приоритет: во время них кольцо не перебивается.

## Как подобрать цвета

1. Включи «Ручной тест» и нажми основной цвет, который хочешь поправить
   (например, «Оранжевый»).
2. В разделе «Цвета основных точек» измени поле этого цвета так, чтобы на
   колонке он выглядел правильно. Кольцо меняется сразу.
3. Повтори для остальных цветов; отдельно проверь белый — он задаёт оттенок
   белого и баланс каналов.
4. Включи «Авто (обложка)»: та же коррекция применяется ко всей палитре
   обложки через интерполяцию между восемью точками.
5. Нажми «Сохранить», если хочешь записать сразу; иначе запись произойдёт
   сама в течение двух секунд.

## Сохранение

Настройки лежат в `/data/local/capsula-airplay/panel.json`. Запись
отложенная, не чаще раза в 2 секунды, чтобы не изнашивать flash. После
перезагрузки кольцо всегда стартует в авторежиме; калибровка сохраняется.

## API

- `GET /api/state` — конфиг, последние записанные цвета, состояние сессии,
  палитра обложки, уровень сигнала, модель железа.
- `POST /api/state` — заменить конфиг целиком (JSON, до 256 КиБ).
  `lut` — 27 узлов таблицы 3×3×3 в порядке `i*9 + j*3 + k`, где каждая ось
  принимает 0, 0.5 и 1. Узел — цвет, который уходит в кольцо для этого входа;
  по умолчанию таблица единичная.
- `POST /api/save` — записать текущий конфиг немедленно.
- `POST /api/reset` — вернуть значения по умолчанию.

## Ограничения

Панель слушает все интерфейсы, без пароля. Она умеет менять только кольцо
и параметры рендера; файлов, команд и громкости не касается. Не открывайте
порт 8088 в интернет.
