# Релиз v1.5.1

## Что нового

Главное — **музыка на стоковых колонках больше не прерывается** при быстром
профиле −1,7.

- Новые PCM-блоки сразу подаются в PulseAudio, `minreq` 5 мс.
- Буфер увеличен с 0,10 до **0,15 с**, смещение **−1,7** сохранено.
- Контролируемый тон 440 Гц через реальный backend:
  на 2019 при 0,10 — 9–20 underflow и провалы до 244 мс;
  при 0,15 и 0,25 — **0 underflow и 0 провалов >= 1 мс** в четырёх прогонах.
  На Мини после исправления — 0 провалов.
- Обе колонки: общий renderer палитры (JPEG/PNG/TIFF), переход 300 мс,
  пульсация по реальному исходящему PCM. Цвета берутся из обложки трека.
- Мини: native-громкость через проверяемый 8-байтный guard patch
  стокового `voice-agent`, flat-профиль, единая громкость телефона, кнопок
  и цифрового индикатора. Исправлена metadata-сборка: без
  `CONFIG_METADATA*` обложки не сохранялись.
- 2019: тот же аудиобэкенд и renderer. UI и LED-брокер читают журнал
  потоком, а не полным снимком дважды в секунду. Часы, приоритет штатных
  анимаций и жест ладонью (pause/play) сохранены.

## Проверено

- PA-backend selftest и tone-test на обеих стоковых колонках.
- Владелец прослушал обе колонки: музыка, обложка, пульсация; на Мини
  также кнопки и громкость.
- Владелец подтвердил на слух синхрон с Алисой при смещении −1,7.
- Checksums пакетов, C-тесты порогов/громкости, Go race-тесты renderer’а.

## Установка

```sh
sh install.sh --check --upgrade   # проверить условия
sh install.sh --upgrade           # установить или обновить
```

`install.sh` сам выбирает пакет по прошивке. На стоковой Мини команды
выполняются через ADB от root. Обновление приёмника не требует перезагрузки;
перезагрузка нужна только для первого применения патча `voice-agent`
на Мини.

## Ограничения

- Инструментально акустическая задержка не измерялась. Синхрон с Алисой
  при −1,7 владелец подтвердил на слух.
- Холодная загрузка после этих изменений не перепроверялась.
- Причина прежней самопроизвольной перезагрузки Мини не установлена.
- Проверенная прошивка Мини — 44.90.
- Alpine-пакет не менялся и сохраняет профиль 0,10.

## Откат

Предыдущий конфиг сохранён на устройстве как
`shairport-sync.conf.before-015`. Прежние бинарники остаются в `/data`;
`uninstall.sh` возвращает стоковые файлы Мини из `/rom` и требует ручную
перезагрузку.
