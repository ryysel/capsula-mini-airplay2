# Neutral/dark artwork palette

Shipped in v1.6.0-rc.3 for both stock Capsules.
Neutral/shadow area contributes to palette proportions; chroma preference
is bounded at 1..1.25. Hue-family clusters average source brightness before
saturation correction; no forced 55% minimum brightness remains.

The private Hybrid Theory reproduction changed from ten RGB(140,0,0)
stops plus warm highlights to two RGB(43,0,0) and ten RGB(76,76,76).
These are logical palette values, not photometric measurements.
No copyrighted cover fixture or device capture is included in the archive.
Synthetic regressions and an optional private-image probe cover this policy.
Owner accepted the Mini result; identical palette code is deployed on Big.
