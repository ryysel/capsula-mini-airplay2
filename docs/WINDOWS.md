# Установка с Windows (без прошивки)

Нужны Windows 10/11 с OpenSSH Client, уже установленная Alpine **3.24/aarch64**,
работающий root SSH и настроенный ALSA `default`. Установщик НЕ переводит
стоковую Капсулу в Alpine, не прошивает NAND и не подбирает пароли.

1. Скачайте архив релиза, **распакуйте** целиком. Не запускайте из ZIP.
2. Запустите `Install-Windows.cmd` обычным двойным щелчком (администратор не нужен).
3. Введите адрес колонки, SSH-порт и при необходимости путь к своему SSH-ключу.
   Пустой путь оставляет обычную аутентификацию OpenSSH (агент/пароль).
4. При первом подключении сверьте fingerprint SSH-ключа с известным ключом
   устройства. Не принимайте неизвестный ключ вслепую. Изменение ключа — ошибка,
   установщик не удаляет `known_hosts` и не отключает проверку.
5. Прочитайте preflight и введите `INSTALL`. Ввод пароля идёт в OpenSSH,
   не сохраняется установщиком. Пароль может запрашиваться несколько раз.
6. Дождитесь `INSTALL_PASS`. Выберите колонку в AirPlay, проверьте звук.

Если нет `ssh.exe`/`scp.exe`: Параметры Windows → Дополнительные компоненты →
Клиент OpenSSH. Если `tar.exe` отсутствует, обновите Windows.

Установщик проверяет SHA256 локального комплекта и повторно на колонке.
Манифест в том же архиве защищает от повреждения, но не заменяет доверие к
источнику загрузки. Не запускайте чужие перепакованные архивы.

## Имя из /etc/hostname

На новой установке AirPlay-имя читается из `/etc/hostname` выбранной колонки,
а не из имени Windows-ПК. Повторная установка сохраняет имеющийся конфиг и
имя комнаты. Это снимок имени при установке, не фоновая синхронизация.

Для явного перехода на hostname из SSH, из каталога распакованного комплекта:

```sh
sh install.sh --upgrade --hostname
```

Или своё имя: `sh install.sh --upgrade --name 'Capsula Mini AirPlay (Hall)'`.
Предел 50 байт UTF-8 (из-за RAOP); управляющие символы, кавычки и обратные
слеши запрещены. `/etc/hostname` установщик сам не изменяет.

## Что меняется

Только shairport-sync/nqptp, их конфиг/службы и APK-зависимости avahi/библиотек.
При обновлении приёмник и nqptp останавливаются до замены бинарников.
ALSA, твикер, triggerhappy, кнопки, Wi-Fi, SSH, загрузчик и прошивка не меняются.
Новые TCP/WAN-правила не создаются. Нужен обычный доверенный LAN.

## Если установка оборвалась

Не повторяйте прошивку! Посмотрите последнюю ошибку. До замены файлов создаётся
каталог `/root/airplay2-backup-XXXXXXXX` с правами 700: `files/` содержит старые
файлы с абсолютной структурой путей, `apk-world.before` и `runlevels.before`
фиксируют исходное состояние. APK и службы не откатываются автоматически.

Для отката существовавшей установки: остановите shairport-sync и nqptp,
скопируйте **проверенные** старые файлы из `files/` обратно по тем же путям,
сохраните права, запустите старые службы. После первой установки (без старых
файлов) используйте `uninstall.sh`; он удаляет весь конфиг, сначала сохраните его.
Не восстанавливайте `/etc/apk/world` простым копированием: это только снимок.

## Статус проверки

Проверка синтаксиса PowerShell, SHA256 из распакованного комплекта и mock-проверка
пошагового сценария не равны установке с реального Windows на реальную колонку.
До такой приёмки Windows-мастер считается экспериментальным.
