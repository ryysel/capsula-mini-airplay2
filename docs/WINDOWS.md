# Установка с Windows (без прошивки)

Нужны Windows 10/11 с OpenSSH Client, уже установленная Alpine **3.24/aarch64**,
работающий root SSH и настроенный ALSA `default`. Установщик НЕ переводит
стоковую Капсулу в Alpine, не прошивает NAND и не подбирает пароли.

## Как узнать адрес колонки

Установщик не сканирует всю подсеть. При запуске без адреса он проверяет:

1. **USB-адрес** `192.168.14.14` — он фиксирован в образах Капсулы. Подключите
   колонку USB-кабелем к ПК, дождитесь нового сетевого адаптера (Windows обычно
   ставит драйвер RNDIS/CDC сам) и выберите этот адрес.
2. **Устройства из ARP-таблицы ПК** с открытым портом 22 — те, с кем ПК уже
   обменивался трафиком (роутер, сервер, колонка). Список выводится
   пронумерованным: можно выбрать номер или ввести адрес вручную.

Если список пуст или колонки в нём нет:

- посмотрите IP в списке DHCP на роутере (устройство `vk-mini-…`);
- попробуйте имя `<hostname>.local` (например, `vk-mini-a113x.local`) —
  Windows 10/11 умеет mDNS;
- введите адрес вручную.

Проверка без установки: `-DiscoverOnly` печатает найденных кандидатов.

1. Скачайте архив релиза, **распакуйте** целиком. Не запускайте из ZIP.
2. Запустите `Install-Windows.cmd` обычным двойным щелчком (администратор не нужен).
3. Введите адрес колонки, SSH-порт, при необходимости путь к своему SSH-ключу и
   AirPlay-имя (Enter — взять `/etc/hostname` колонки).
4. При первом подключении сверьте fingerprint SSH-ключа с известным ключом
   устройства. Не принимайте неизвестный ключ вслепую. Установщик не удаляет
   `known_hosts` и не отключает проверку.
5. Прочитайте preflight и введите `INSTALL`. Пароль вводится в OpenSSH и не
   сохраняется установщиком; он может запрашиваться несколько раз.
6. Дождитесь `INSTALL_PASS bridge=yes|no`. Выберите колонку в AirPlay.

Если нет `ssh.exe`/`scp.exe`: Параметры Windows → Дополнительные компоненты →
Клиент OpenSSH. Если нет `tar.exe`, обновите Windows.

Установщик проверяет SHA256 локального комплекта и повторно на колонке.
Манифест защищает от повреждения архива, но не заменяет доверие к источнику.

## Автоматический запуск (для проверки и скриптов)

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File windows\Install-AirPlay.ps1 `
  -HostName 192.168.0.168 -Port 22 -KeyFile C:\keys\id_ed25519 `
  -Name "VK Capsula Mini AirPlay (Коридор)" -Yes
```

`-ValidateOnly` проверяет только локальный комплект, без сети.
Без `-Yes` мастер всегда спрашивает подтверждение `INSTALL`.

## Имя

По умолчанию имя берётся из `/etc/hostname` **колонки** при установке.
Повторная установка сохраняет уже заданное имя; `-Name`/`--name` задаёт своё,
`--hostname` явно перечитывает hostname. Предел 50 байт UTF-8 (из-за RAOP);
управляющие символы, кавычки и обратные слеши запрещены. `/etc/hostname`
установщик не меняет.

## Что меняется

- Приёмник, `nqptp`, их конфиг и службы; APK-зависимости (`avahi`, `dbus`,
  `glib` и библиотеки).
- D-Bus policy `org.gnome.ShairportSync`.
- Если работает `capsule-mini-tweaker` (`/run/capsule-controls.sock`): служба
  `ap2-bridge`, `ignore_volume_control` и двусторонняя громкость.
- ALSA, твикер, triggerhappy, кнопки, Wi-Fi, SSH, загрузчик и прошивка не меняются.
  Новые TCP/WAN-правила не создаются.

При обновлении приёмник, `nqptp` и мост останавливаются до замены бинарников.
Перед изменениями создаётся `/root/airplay2-backup-XXXXXXXX` (700) с прежними
файлами (`files/` с абсолютными путями), `apk-world.before` и
`runlevels.before`. Автоматического полного отката нет: APK и службы не
восстанавливаются сами.

## Откат

Остановите `ap2-bridge`, `shairport-sync` и `nqptp`, верните проверенные файлы
из `files/` по тем же путям, восстановите права и запустите прежние службы.
`/etc/apk/world` не копируйте обратно — это только снимок. После первой
установки используйте `uninstall.sh` (он удаляет и конфиг — сохраните его).

## Статус проверки

Проверено на реальной колонке: чистая установка с Windows через этот мастер,
имя с кириллицей, включение моста, холодная перезагрузка (службы, mDNS, D-Bus
и громкость вернулись сами), воспроизведение и регулировка громкости
ползунком и кнопками, в том числе ползунком до старта трека.
Автопоиск проверен отдельно (`-DiscoverOnly`).
