# Как уменьшен размер поставки — 15.11.2026

Ориентир — сборка Station AirPlay для Яндекс Станций: там весь приёмник
(AirPlay 2, nqptp, супервизор, индикация) укладывается в один архив
~4,9 МБ. Ниже — что именно они делают и что из этого применено у нас.

## Что делает Station AirPlay

Их скрипты сборки (`scripts/build-airplay2.sh`, `.github/workflows/ci.yml`):

- **C/C++**: `-Os`, `-flto`, `-ffunction-sections -fdata-sections`,
  `-Wl,--gc-sections`, `-mthumb`, `-ffile-prefix-map` для воспроизводимости;
  ffmpeg собирается с `--enable-small --disable-everything` и только нужными
  декодерами (aac, alac, pcm_s16be), демоны — без systemd, D-Bus, MPRIS, soxr;
  всё лишнее вырезается `strip`.
- **Go-супервизор**: `CGO_ENABLED=0`, `-buildvcs=false -trimpath`,
  `-ldflags='-s -w'`, затем `upx --best --lzma` и проверка `upx -t`.
- **Упаковка**: один `.yap`/`.yampkg`, сжатый xz.
- Заявляют, что распаковка UPX не требует ничего на колонке и что после смены
  упаковщика нужно проверять реальный запуск и `os.Executable()`.

## Что применено у нас

| Что | Было | Стало |
|---|---:|---:|
| `capsula-ui` (рендерер + панель) | 8,28 МиБ | **1,58 МиБ** |
| сборка: `go build -trimpath -ldflags="-s -w"` + `upx --best --lzma` | — | — |
| пакет на диске, Мини | 14,5 МиБ | **5,3 МиБ** |
| пакет на диске, 2019 | 27,9 МиБ | **5,4 МиБ** |

Дополнительно удалены файлы прошлых экспериментов (их копии лежат на RAID,
в git не попадают):

- Мини: `bin/shairport-sync.prev` — 2,9 МиБ;
- 2019: `ui-trial/` — 7,9 МиБ, `shairport-sync.pre-volume-fix`,
  `shairport-sync.sinkgain` — 5,8 МиБ, плюс отработавшие `.bak` конфиги.

Итог по `/data`: свободно 28,5 МиБ на Мини и 52,8 МиБ на 2019 (было 22,0 и
30,3 МиБ).

## Что сознательно не делали

- **`shairport-sync` не пересобирали с `-Os/-flto`.** Сейчас он уже 2,9 МиБ
  (у Station AirPlay — 3,8 МиБ) и собран `-O3`; экономия была бы ~0,4–0,6 МиБ,
  а риск для только что вычищенного звука (underrun, тайминги) выше выгоды.
- **Патченный `voice-agent` пока не упакован.** Он лежит в оверлее целиком
  (13,4 МиБ) из-за 8-байтного патча громкости; UPX сжимает его до 3,7 МиБ
  (проверено: упакованный бинарник запускается и ведёт себя как обычный).
  Это ещё **−9,6 МиБ**, но трогает стоковый сервис, который сторожит
  watchdog, поэтому решение за владельцем.

## Как воспроизвести

```sh
docker run --rm -v "$PWD":/src -w /src golang:1.23-bookworm \
  sh -ec 'CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -buildvcs=false \
    -trimpath -ldflags="-s -w" -o /src/capsula-ui .'
upx --best --lzma capsula-ui
upx -t capsula-ui
```

Готовый бинарник в `packages/*/bin/capsula-ui` упакован; для чтения символов
и `go version -m` разверните его `upx -d`.
