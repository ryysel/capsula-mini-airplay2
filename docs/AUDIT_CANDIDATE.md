# 1.6.1-dev.1 — локальный кандидат

Собрать модельные TAR.GZ: `python3 build/build-model-packages.py <каталог>`.
Используйте архив только своей модели. После распаковки `sh install.sh`
выбирает пакет по устройству. `mini-stock` — Buildroot, `mini-a113x` —
Alpine. Лицензии, исходники модели и проверка пакета сохранены.
Windows-мастер для Alpine остаётся отдельным. На устройствах кандидат не проверен.

Mini сохраняет сжатый снимок bin, etc, init.d, S99airplay и калибровки вне
каталога установки; архив не включает посторонние экспериментальные каталоги.
`--check` учитывает фактический размер сжатого снимка. Старые копии остаются.
На большой резервируются изменяемые файлы, при ошибке выполняется восстановление.
Установку и удаление проверять на стенде; удаление не сбрасывает калибровку.

Большая: добавлены показатели первой жёсткой коррекции на старте.
Профиль −1,7 с / 150 мс и алгоритм синхронизации не менялись.
Панель собирается Go 1.26; про доступ и сохранение см. PANEL.md.

Из корня исходников: `sh tests/check-audit-candidate.sh` (Linux, Go 1.26, C-компилятор и Python 3). Smoke-тест отката использует временные файлы, не процессы колонки.
