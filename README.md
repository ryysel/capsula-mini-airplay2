# AirPlay 2 для VK Капсулы и Капсулы Мини

Музыка с iPhone, iPad и Mac на колонках VK: **Капсула 2019** и **Капсула Мини**.
Приёмник работает рядом с существующей системой — этот проект **не прошивает и не взламывает колонку**.

## Возможности

| | Капсула 2019 | Капсула Мини |
|---|---|---|
| Требуемая система | Стоковый Buildroot, root, RK3308 | Alpine 3.24, A113X, aarch64 |
| AirPlay 2 | Да | Да |
| Одна громкость: телефон ↔ кнопки | Через `voice-agent` и `stereoctl` | Через `capsule-tweaker` и мост D-Bus |
| Пауза / продолжение | Прикладывание ладони | Верхняя кнопка ассистента |
| Кольцо в цветах обложки | Да | Да |
| Вне AirPlay | Часы на кольце, штатное мурчание | Обычная индикация и цифровые часы |
| Значок в AirPlay | Большая колонка | Мини-колонка |

Управление жестом/кнопкой действует только при живом сеансе AirPlay. На большой Капсуле мурчание на это время приглушается; без AirPlay оно возвращается. На Мини кнопка сохраняет обычное действие вне сеанса и во время работы ассистента.

Обложку присылает приложение-отправитель. Кольцо показывает плавный градиент её цветов, без выдуманных обложек и сетевого поиска. Поддерживаются JPEG, PNG и TIFF; смена палитры — с переходом 300 мс. Это **заливка обложки, не спектроанализатор и не пульсация в такт музыке**. Без обложки остаётся обычная индикация. Речь ассистента и индикация громкости имеют приоритет.

## Перед установкой

- Нужны root-доступ и резервная копия существующей установки.
- Для Капсулы 2019 проверена прошивка **44.90**. Патчер `voice-agent` сверяет SHA-256 и откажется менять неизвестный бинарник. Другие версии не заявлены.
- Мини должна уже работать на **Alpine 3.24/aarch64**, с настроенным `/etc/asound.conf`. Для кнопок, кольца и общей громкости нужны `capsule-tweaker`, `ringled` и `marusya-hw` с настроенным `marusya-wake`. На стоковую прошивку Мини этот пакет не ставится.
- Нужна общая локальная сеть с доступным mDNS и PTP. Не открывайте ADB/SSH и порты приёмника в интернет.
- На Капсуле 2019 **нельзя останавливать `voice-agent`**: это может вызвать сброс аппаратным watchdog. Установщик его не останавливает и не перезагружает колонку.

## Установка и обновление

Команды ниже выполняются **от root на колонке**, из распакованного каталога. На Windows распакуйте отдельный Mini-архив и запустите `Install-Windows.cmd` — [инструкция](docs/WINDOWS.md).

### Капсула 2019

```sh
sh install.sh                         # сохранить имя и существующий конфиг
sh install.sh 'VK Capsula AirPlay'     # либо задать своё имя
```

Установщик сохраняет предыдущие файлы в `/data/local/capsula-airplay/backups/`, обновляет приёмник и оформление, добавляет поздний автозапуск. Базовая прошивка и аккаунт не заменяются. При первой установке патча громкости понадобится **одна ручная перезагрузка**; при обновлении уже пропатченной колонки она не нужна.

Проверка:

```sh
/data/local/capsula-airplay/init.d/shairport-sync status
/data/local/capsula-airplay/init.d/capsula-ui status
```

### Капсула Мини

```sh
sh install.sh --check --upgrade        # проверить условия без изменений
sh install.sh --upgrade               # обновить с резервной копией
sh install.sh --upgrade --name 'VK Mini AirPlay'
```

Сохраняются существующие имя, ALSA и настройки громкости. С v1.4.1 параметры задержки обновляются до быстрого профиля даже при обновлении существующей установки. Резервная копия — `/root/airplay2-backup-*`. Установщик не меняет прошивку и сеть. При наличии брокера кнопка получает AirPlay-режим; без необходимых компонентов дополнительные функции недоступны.

```sh
rc-service shairport-sync status
rc-service ap2-bridge status
rc-service capsula-art status
```

### Подключение с телефона

Откройте выбор аудиовыхода AirPlay в приложении или Пункте управления, выберите колонку и включите трек. Проверьте громкость с телефона и кнопок, паузу/продолжение и смену цветов на следующем треке. После смены имени или модели iOS может некоторое время показывать старое объявление из кэша.

Имя ограничено **50 байтами UTF-8**, не 50 буквами. Длинные русские имена могут обрезаться. Имя и комната задаются владельцем, адреса и аккаунты тестовых устройств в пакет не зашиты.

## Задержка и ограничения

- **Обе Капсулы:** с v1.4.1 быстрый профиль, как у последней Station-airplay: буфер **0,10 с**, смещение **−1,7 с**, `resync_threshold_in_seconds = 0.050`, `drift_tolerance_in_seconds = 0.002`. Обновление применяет эти параметры и к существующему конфигу, сохраняя имя и управление громкостью.
- Отрицательное смещение ускоряет начало воспроизведения, но **не гарантирует одинаковую акустическую задержку с Алисой** и нарушает синхронизацию с видео/другими приёмниками. На большой Капсуле ранее сообщалось о заиканиях при `-1.0/0.1`; причина не доказана контролируемым замером. Профиль `-1.7/0.1` применён на устройствах, но отдельного подтверждённого A/B звука пока нет.
- Для консервативного режима при установке: `sh install.sh --timing synchronized` (2019) или `sh install.sh --upgrade --timing synchronized` (Мини). Это возвращает **0,20 с / 0,0**. Для быстрого режима: `--timing fast_audio` (по умолчанию).
- Приложения без обложек не дают цветовую палитру. Устаревшая или отсутствующая обложка не является доказательством поломки звука.
- Проверка вживую: на Капсуле 2019 подтверждены музыка, общая громкость в обе стороны, жест pause/play и цвета кольца. После последних изменений задержки и приглушения мурчания нужна повторная проверка на слух. На Мини проверены службы, декодирование, вывод тестовой палитры и ветки кнопки; финальная проверка с телефоном ещё требуется.
- Автозапуск новых функций установлен, но полная проверка холодной загрузки этого релиза не выполнялась.

## Откат и удаление

```sh
sh uninstall.sh
```

Удаляется пакет выбранной модели. На Капсуле 2019 снятие патча `voice-agent` вступает в силу после ручной перезагрузки. Мини возвращает сохранённый обработчик кнопки; зависимости и `/etc/asound.conf` не удаляются.

Для **возврата предыдущей версии**, а не удаления, используйте резервную копию установщика. Сохраните её до проверки обновления. Не восстанавливайте чужие `userdata`, аккаунты и дампы.

## Разработка

Приёмник: [Shairport Sync](https://github.com/mikebrady/shairport-sync) 5.6.2; синхронизация: [NQPTP](https://github.com/mikebrady/nqptp) 1.2.9.

| Каталог | Содержимое |
|---|---|
| `packages/capsula-2019/` | Buildroot/glibc, PulseAudio, нативная громкость, LED-брокер |
| `packages/mini-a113x/` | Alpine/musl, ALSA, D-Bus, оформление и управление |
| `build/` | Скрипты сборки и локальные патчи приёмника |
| `packages/*/src/` | Исходники демонов оформления и тесты |
| `windows/`, `tests/` | Мастер Мини и проверки установщика |

Конфиги и init-скрипты поставляются вместе с бинарниками. Файлы каждого пакета проверяются по его `SHA256SUMS`. Не запускайте бинарник от одной модели на другой: архитектура ARM64 одинаковая, но libc и аудиотракт разные.
