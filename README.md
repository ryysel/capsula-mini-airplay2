# AirPlay 2 для VK Капсулы и Капсулы Мини

Музыка с iPhone, iPad и Mac на колонках VK: **Капсула 2019**, **Капсула Мини на Alpine** и **Капсула Мини на родной прошивке**.
Приёмник работает рядом с существующей системой — этот проект **не прошивает и не взламывает колонку**.

## Возможности

| | Капсула 2019 | Мини, Alpine 3.24 | Мини, родная ОС |
|---|---|---|---|
| Требуемая система | Стоковый Buildroot, root, RK3308 | Alpine 3.24, A113X, aarch64 | Стоковый Buildroot, root/ADB, A113X |
| AirPlay 2 | Да | Да | Да |
| Одна громкость: телефон ↔ кнопки | Через `voice-agent` и `stereoctl` | Через `capsule-tweaker` и мост D-Bus | Через `voice-agent` и `stereoctl`, патч двух условий |
| Пауза / продолжение | Прикладывание ладони | Верхняя кнопка ассистента | Верхняя кнопка (`KEY_PLAYPAUSE`) |
| Кольцо в цветах обложки | Да | Да | Да, 12 RGB-пикселей |
| Вне AirPlay | Часы на кольце, штатное мурчание | Обычная индикация и цифровые часы | Штатная индикация и часы |
| Значок в AirPlay | Большая колонка | Мини-колонка | Мини-колонка |

Управление кнопкой действует только при живом сеансе AirPlay. На большой Капсуле мурчание на это время приглушается; без AirPlay оно возвращается. На Мини кнопка сохраняет обычное действие вне сеанса и во время работы ассистента.

Обложку присылает приложение-отправитель. Кольцо показывает плавный градиент её цветов, без выдуманных обложек и сетевого поиска. Яркость теперь следует RMS/peak исходящего PCM. Поддерживаются JPEG, PNG и TIFF; смена палитры — с переходом. Это **заливка обложки, не спектроанализатор но яркость пульсирует по уровню музыки**. Без обложки остаётся обычная индикация; на стоковой Мини — слабое белое дыхание. Речь ассистента и индикация громкости имеют приоритет.

## Перед установкой

- Нужны root-доступ и резервная копия существующей установки.
- **Капсула 2019:** проверена прошивка **44.90**. Патчер `voice-agent` сверяет SHA-256 и откажется менять неизвестный бинарник. Другие версии не заявлены.
- **Мини, Alpine:** должна уже работать на **Alpine 3.24/aarch64**, с настроенным `/etc/asound.conf`. Для кнопок, кольца и общей громкости нужны `capsule-tweaker`, `ringled` и `marusya-hw` с настроенным `marusya-wake`.
- **Мини, родная ОС:** проверена прошивка **44.90** (Buildroot 2022.11.1, glibc 2.33, PulseAudio 16.1). Нужен root (ADB) и хотя бы 25 МиБ свободных в `/data`. Прошивка, аккаунт и OTA не заменяются. Для единой громкости в оверлей
ставится проверяемый 8-байтный патч `voice-agent`; нужна одна ручная перезагрузка.
- Нужна общая локальная сеть с доступным mDNS и PTP. Не открывайте ADB/SSH и порты приёмника в интернет.
- На Капсуле 2019 **нельзя останавливать `voice-agent`**: это может вызвать сброс аппаратным watchdog. Установщик его не останавливает и не перезагружает колонку.

## Установка и обновление

Команды ниже выполняются **от root на колонке**, из распакованного каталога. `install.sh` сам определяет модель и систему и вызывает нужный пакет:

| Система | Что запустится |
|---|---|
| Alpine 3.24, aarch64 | `packages/mini-a113x/` |
| Buildroot, RK3308 (Капсула 2019) | `packages/capsula-2019/` |
| Buildroot, Amlogic A113X (Мини) | `packages/mini-stock/` |

```sh
sh install.sh --check      # только проверить условия
sh install.sh              # установить или обновить
```

Для явного выбора пакета можно вызвать его установщик напрямую. Параметры (`--name`, `--timing`, `--upgrade`) зависят от пакета.

### Капсула 2019

```sh
sh install.sh                         # сохранить имя и существующий конфиг
sh install.sh 'VK Capsula AirPlay'     # либо задать своё имя
```

Установщик сохраняет предыдущие файлы в `/data/local/capsula-airplay/backups/`, обновляет приёмник и оформление, добавляет поздний автозапуск. Базовая прошивка и аккаунт не заменяются. При первой установке патча громкости понадобится **одна ручная перезагрузка**; при обновлении уже пропатченной колонки она не нужна.

Проверка:

```sh
/data/local/capsula-airplay/init.d/shairport-sync status
/data/local/capsula-airplay/init.d/capsula-ui status
```

### Капсула Мини на Alpine 3.24

```sh
sh install.sh --check --upgrade        # проверить условия без изменений
sh install.sh --upgrade               # обновить с резервной копией
sh install.sh --upgrade --name 'VK Mini AirPlay'
```

Сохраняются существующие имя, ALSA и настройки громкости. С v1.4.1 параметры задержки обновляются до быстрого профиля даже при обновлении существующей установки. Резервная копия — `/root/airplay2-backup-*`. Установщик не меняет прошивку и сеть. При наличии брокера кнопка получает AirPlay-режим; без необходимых компонентов дополнительные функции недоступны.

```sh
rc-service shairport-sync status
rc-service ap2-bridge status
rc-service capsula-art status
```

### Капсула Мини на родной ОС

Ставится поверх стокового Buildroot: файлы кладутся в `/data/local/capsula-airplay`, прошивка в `/rom` не трогается. Для общей громкости ставится 8-байтный
патч `voice-agent` в оверлей (44.90, точный SHA-256); после первой установки
нужна одна ручная перезагрузка. Нужен root через ADB.

```sh
adb connect <IP-??????????????>:5555
adb shell
sh install.sh --check --upgrade   # условия, без изменений
sh install.sh --upgrade           # установка с резервной копией
sh install.sh --upgrade --name 'VK Capsula Mini AirPlay'
```

Особенности:

- Имя в конфиге по умолчанию — `VK Capsula Mini AirPlay`; комната задаётся именем (`VK Capsula Mini AirPlay (Спальня)`).
- После установки проверьте `pidof shairport-sync nqptp` и порт 7000; затем **перезагрузите** колонку и убедитесь, что всё поднялось само.
- Автозапуск: `/etc/init.d/S99airplay` плюс замена стокового `/etc/init.d/S50avahi-daemon` через оверлей. Без этой замены автозапуск не работает: `rcS` раскрывает список скриптов до монтирования оверлея (S04), поэтому чисто оверлейный `S99` при загрузке не выполняется. Подробности — [docs/MINI_STOCK.md](docs/MINI_STOCK.md).
- OTA-обновление пакет **не отключает**. Это отдельное действие владельца; стоковый `fwupdater` остаётся на месте.
- Резервные копии: `/data/local/capsula-airplay.backup-*`.

Проверка:

```sh
/data/local/capsula-airplay/S99airplay status
netstat -ltn | grep 7000
avahi-browse -t -p _airplay._tcp | grep -i mini
```

### Подключение с телефона

Откройте выбор аудиовыхода AirPlay в приложении или Пункте управления, выберите колонку и включите трек. Проверьте громкость с телефона и кнопок, паузу/продолжение и смену цветов на следующем треке. После смены имени или модели iOS может некоторое время показывать старое объявление из кэша.

Имя ограничено **50 байтами UTF-8**, не 50 буквами. Длинные русские имена могут обрезаться. Имя и комната задаются владельцем, адреса и аккаунты тестовых устройств в пакет не зашиты.

## Панель кольца

На обеих стоковых колонках работает веб-панель: `http://<ip-колонки>:8088/`.
Порт 80 занят стоковым `voice-agent`, поэтому панель слушает 8088.

- кольцо из 12 пикселей: каждый красится отдельно, есть заливка и белый;
- основные цвета (красный, зелёный, синий, белый, жёлтый, голубой, пурпурный,
  оранжевый) — заливают кольцо одним нажатием;
- калибровка каждой из десяти точек (чёрный, серый, R/G/B, жёлтый, голубой,
  пурпурный, оранжевый, белый): задаётся цвет, который реально уходит в
  кольцо; по этим точкам интерполируется палитра обложки. Чёрная точка
  задаёт свечение для чёрной обложки или её отсутствия;
- автосохранение с кнопкой «Сохранить» и отметкой «Сохранено в …»;
- живая настройка яркости, пульсации, насыщенности и плавности;
- ручной режим сразу выводится на кольцо, предпросмотр в браузере повторяет
  записанные цвета;
- калибровка сохраняется на колонке, после перезагрузки кольцо стартует
  в авторежиме.

Панель доступна только в локальной сети и без пароля. Она не принимает
команды и не читает файлы — только цвета кольца и параметры рендера.

## Задержка и ограничения

- **Стоковые колонки:** быстрый профиль — буфер **0,15 с**, смещение **−1,7 с**, `resync_threshold_in_seconds = 0.050`, `drift_tolerance_in_seconds = 0.002`. Обновление применяет эти параметры и к существующему конфигу, сохраняя имя и управление громкостью. Буфер 0,10 при −1,7 на стоковом PulseAudio давал underflow и прерывания; 0,15 устраняет их в контролируемом тоне на обеих колонках.
- Отрицательное смещение ускоряет начало воспроизведения, но **не гарантирует одинаковую акустическую задержку с Алисой** и нарушает синхронизацию с видео/другими приёмниками. На этих колонках синхрон с Алисой при −1,7 владелец подтвердил на слух; инструментально задержка не измерялась.
- Alpine-пакет сохраняет прежний профиль (0,10/0,0 по умолчанию) и в этой версии не менялся.
- Для консервативного режима: `--timing synchronized` (0,20 с / 0,0). Быстрый режим: `--timing fast_audio` (по умолчанию).
- Приложения без обложек не дают цветовую палитру. Устаревшая или отсутствующая обложка не является доказательством поломки звука.
- **Родная Мини:** кольцо — 36 каналов на 12 RGB-пикселей через `/dev/topleds`; порядок каналов повторяет стоковый `voice-agent`. Часы (`is31fl32xx`) и кольцо — разные устройства, пакет их не смешивает. Штатные анимации ассистента и громкости имеют приоритет.
- Проверка вживую: владелец подтвердил воспроизведение на обеих стоковых колонках и синхрон с Алисой на слух. На стоковой Мини отдельно проверены цвета обложки, пульсация и кнопки; на 2019 — музыка после переноса того же бэкенда. На Мини (Alpine) проверены службы, декодирование, вывод тестовой палитры и ветки кнопки.

## Откат и удаление

```sh
sh uninstall.sh
```

Удаляется пакет выбранной модели. На Капсуле 2019 снятие патча `voice-agent` вступает в силу после ручной перезагрузки. Мини на Alpine возвращает сохранённый обработчик кнопки; зависимости и `/etc/asound.conf` не удаляются. На стоковой Мини удаляются файлы пакета и оверлейная замена `S50avahi-daemon`; стоковые скрипты и прошивка остаются.

Для **возврата предыдущей версии**, а не удаления, используйте резервную копию установщика. Сохраните её до проверки обновления. Не восстанавливайте чужие `userdata`, аккаунты и дампы.

## Разработка

Приёмник: [Shairport Sync](https://github.com/mikebrady/shairport-sync) 5.6.2; синхронизация: [NQPTP](https://github.com/mikebrady/nqptp) 1.2.9.

| Каталог | Содержимое |
|---|---|
| `packages/capsula-2019/` | Buildroot/glibc, PulseAudio, нативная громкость, LED-брокер |
| `packages/mini-a113x/` | Alpine/musl, ALSA, D-Bus, оформление и управление |
| `packages/mini-stock/` | Стоковый Buildroot/glibc, PulseAudio, кольцо и кнопки |
| `build/` | Скрипты сборки и локальные патчи приёмника |
| `packages/*/src/` | Исходники демонов оформления и тесты |
| `windows/`, `tests/` | Мастер Мини (Alpine) и проверки установщика |

Конфиги и init-скрипты поставляются вместе с бинарниками. Файлы каждого пакета проверяются по его `SHA256SUMS`. Не запускайте бинарник от одной модели на другой: архитектура ARM64 одинаковая, но libc, аудиотракт и драйверы индикации разные.
