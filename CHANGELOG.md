# Изменения

## v1.4.1

- Один быстрый аудиопрофиль для обеих Капсул: offset −1.7, backend 0.10, resync 0.050, drift 0.002 — как в последних работах Station-airplay.
- Исправлена миграция: обновление действительно применяет профиль; установщик 2019 больше не принудительно возвращает offset 0.0.
- `--timing synchronized` даёт консервативный откат к 0.0 / 0.20; `--timing fast_audio` — быстрый режим. Имя, громкость и metadata сохраняются.
- Устранено одновременное рисование старого standalone-clock и нового LED-брокера: stop проверяет точный argv, если Busybox killall пропустил процесс.
- Повторный start поднимает отсутствующий компонент оформления, а не завершает проверку только по PID компаньона.
- Добавлены тесты идемпотентной миграции, обоих режимов, отказа на неизвестном формате конфига и обновления существующей установки.

Быстрый профиль применён на обеих колонках; startup-лог большой Капсулы подтвердил значения. Это проверка конфигурации, не доказательство измеренной задержки или устранения заиканий. Публичная поставка не включает аккаунты и конфиги тестовых комнат.

## v1.4.0

- Два пакета: Капсула 2019 (Buildroot/glibc) и Мини (Alpine/musl).
- Большая Капсула: единая громкость через stereoctl и проверяемый патч voice-agent; ладонь pause/play, без мурчания во время сеанса.
- Цвета обложки, JPEG/PNG/TIFF, насыщенная палитра и плавные переходы. Статичная заливка, не пульсация.
- Часы на кольце большой Капсулы вне сеанса; приоритет штатных анимаций.
- Значок большой колонки для 2019, мини-значок для Мини.
- Сохранены Windows-мастер Мини и D-Bus-мост громкости из v1.3.0.
- Обновление с резервными копиями; поздний автозапуск на Buildroot.
- На 2019 отменён эксперимент с отрицательным latency_offset после сообщения о заиканиях. На Мини сохранение существующего конфига при обновлении.

### Проверка

На 2019 владелец проверил музыку, общую громкость, pause/play ладонью и цвета кольца. Откат задержки и приглушение мурчания требуют повторной проверки в живом сеансе. На Мини проверены службы, палитра и логика кнопки с тестовыми состояниями; полный тест с телефоном и холодная загрузка нового релиза ещё не выполнены.
